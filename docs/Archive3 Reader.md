## Summary

A an android app to view and read [archive of our own](https://archiveofourown.org/) works. It tracks reading progress, checks for work updates and more.

It's only for android.

## Technologies

- [Expo]() - app is build in this
- [node-html-better-parser](https://www.npmjs.com/package/node-html-better-parser) - for custom html renderer
